# BookRecommendation 

A dynamic web application that suggests books based on user-selected genres. This project was developed as a Web Technologies course.

## Features
* **Personalized Recommendations:** Users can select multiple genres to get tailored book suggestions.
* **Google Books API Integration:** Fetches real-time book data (title, author, description, and cover image) dynamically.
* **Interactive Modal:** Clicking on "Show Details" opens a pop-up with a longer description and a preview link.
* **Responsive Design:** The UI works smoothly on both desktop and mobile screens.

## Technologies Used
* HTML5
* CSS3 
* JavaScript 
* Google Books API
